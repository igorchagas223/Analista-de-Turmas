📊 Analista de Turmas
O Analista de Turmas é um programa em Python desenvolvido para cadastrar alunos, armazenar suas notas, calcular médias individuais e gerar um relatório de desempenho da turma.

Este projeto foi desenvolvido como um desafio prático focado na manipulação de listas compostas (listas dentro de listas), laços de repetição e formatação de saídas no terminal.

🚀 Funcionalidades
📝 Cadastro Dinâmico: Permite cadastrar quantos alunos o usuário desejar.

🧮 Cálculo de Média: Calcula a média aritmética de duas notas para cada aluno.

📊 Tabela Formatada: Exibe uma listagem organizada com o nome do aluno e sua respectiva média.

🏆 Destaque de Desempenho: Identifica e exibe qual aluno obteve o maior rendimento na turma.

🔢 Contagem Total: Apresenta o número total de alunos cadastrados.

🛡️ Validação de Entrada: Garante que o usuário apenas continue ou encerre o programa com as opções válidas (S ou N).

🛠️ Tecnologias Utilizadas
Linguagem: Python 3

Conceitos Aplicados:

Listas compostas (nested lists)

Fatiamento e cópia de listas ([:])

Estruturas de repetição (while e for)

Enumerador (enumerate())

Formatação de strings (f-strings)

💻 Como Executar o Projeto
Certifique-se de ter o Python 3 instalado em sua máquina.

Clone este repositório ou baixe o código fonte:

Bash
git clone https://github.com/igorchagas223/analista-de-turmas.git
Navegue até o diretório do projeto:

Bash
cd analista-de-turmas
Execute o arquivo Python:

Bash
python main.py
